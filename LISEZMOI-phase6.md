# Phase 6 : visibilité (SEO, Google News) + Tolobana TV
1. Supabase > SQL Editor : exécuter supabase/phase6.sql.
2. Copier le contenu de ce dossier dans le dépôt GitHub (même arborescence), attendre « Ready » dans Vercel.
3. Facultatif, Vercel > Settings > Environment Variables (type Config), puis Redeploy :
   - NEXT_PUBLIC_SITE_URL = https://votre-domaine.info  (dès que vous avez un nom de domaine)
   - NEXT_PUBLIC_GA_ID = G-XXXXXXXXXX  (Google Analytics)
   - NEXT_PUBLIC_GSC_VERIFICATION = code de la balise « Search Console »
4. Search Console : ajouter le site, puis soumettre /sitemap.xml et /news-sitemap.xml.
