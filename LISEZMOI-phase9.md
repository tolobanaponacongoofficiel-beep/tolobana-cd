# Phase 9 : crédibilité et fidélisation
Pages institutionnelles, réglages du média, À la une manuelle, dossiers thématiques, sondages, « Écouter l'article », données structurées Google News renforcées.

## À faire dans l'ordre
1. Supabase > SQL Editor > New query : coller `supabase/phase9.sql`, Run (sans risque si relancé).
2. Copier ce dossier dans le dépôt GitHub (même arborescence). Attendre « Ready » dans Vercel.
3. Vercel > Settings > Environment Variables : `SUPABASE_SECRET_KEY` (déjà ajoutée pour la newsletter) est AUSSI nécessaire pour que les lecteurs puissent voter. Redéployer après ajout.
4. Espace rédaction > « Pages et réglages » : remplir nom de l'éditeur, directeur de la publication, e-mail, adresse. Relire les textes (modèles à valider par un juriste).

## Où trouver quoi
- Lecteurs : pied de page (À propos, Contact, Mentions légales, Charte, Confidentialité, Dossiers, Sondages), menu « Dossiers », sondage du jour dans la colonne de l'accueil, bouton « Écouter cet article ».
- Rédaction (éditeurs) : À la une, Dossiers, Sondages. Administrateurs : Messages reçus, Pages et réglages.
